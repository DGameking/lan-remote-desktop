# 局域网跨平台远程桌面软件 — 产品定义方案（PRD V1.0）

> 产品主理人 Phase 1 产出。注：数据存储字段规范保留原文表述，团长裁决落地采用 JSON Store（见项目档案）。

## 一、定位与价值主张
- 定位：运行在一台 Windows 电脑上的局域网跨平台远程桌面集中管控工具，把 Win/macOS/Linux/飞牛OS 设备汇聚到一张列表，同一界面发现、连接、操作异构设备。
- 一句话价值："一台 Windows 电脑，集中掌控局域网内所有异构设备。"
- 用户画像：家庭多设备用户（主）、小团队/工作室管理员、技术爱好者/NAS 玩家。
- 场景：集中管控（Win 连书房 Mac）、远程协助（连 Linux 工作站）、NAS 管理（连飞牛OS 图形配置）。前置：被控端已开启相应服务（详见第十章配套文档）。

## 二、PRD 七章节

### 第1章 背景
个人与小团队局域网内设备异构，现有方案要么每台装私有客户端，要么需记 IP/协议细节，体验割裂。用户明确不自研被控端、不依赖公网中转，需只做主控端、聚合主流开源协议、开箱即用。

### 第2章 目标
V1.0 完成 Win 主控核心闭环，覆盖 4 类被控平台真实环境连通验证；内测 ≥5 台异构设备。
北极星指标：周成功远程连接会话数（WSCS）。
成功度量：核心闭环成功率≥90%、设备发现命中率≥90%、平台识别准确率≥95%、连接时延 P95≤8s、P0 缺陷=0。埋点默认仅本地，匿名遥测须显式同意。

### 第3章 用户故事
US-01 自动扫描（≥5 台环境 10 分钟发现≥90%）；US-02 手动 IP 添加；US-03 按平台自动推荐协议；US-04 RDP 连 Windows；US-05 VNC 连 mac/Linux/飞牛OS；US-06 手动切协议(P1)；US-07 保存凭据(P1)；US-08 键鼠流畅（2h 无丢失）；US-09 剪贴板(P1)；US-10 画质分辨率(P1)；US-11 首次合规声明确认；US-12 RustDesk 可选(P2)。

### 第4章 功能清单（16 项）
P0（8 项）：F-01 设备自动发现、F-02 手动添加、F-03 设备列表与状态、F-04 协议自动推荐、F-06 RDP 连接、F-07 VNC 连接、F-12 远程键鼠、F-15 安全合规提示。
P1：F-05 手动切协议、F-09 保存凭据、F-10 连接历史、F-13 剪贴板、F-14 画质分辨率、F-16 凭据加密。
P2：F-08 RustDesk、F-11 置顶。
P0 占比 8/16=50% ≤60% ✓。

### 第5章 主流程（含异常分支）
启动→(首次)合规声明→主界面→发现(ARP 需管理员权限则提示/手动降级)→列表(空/离线态)→协议推荐/手动切→凭据(失败可重试/无密码直连)→连接(超时排查/协议不匹配切换)→远程会话(键鼠/剪贴板/画质/断线重连)→断开(记历史)。无断点校验通过。

### 第6章 数据需求
实体：Device/Credential/ConnectionSession/Settings；密码仅存系统加密密文。
埋点表：app_launch/scan_start/scan_complete/device_add/connect_attempt/connect_success/connect_fail/protocol_switch/session_end/credential_save。默认本地，telemetryConsent 开启才上报。

### 第7章 验收标准
逐项可测（发现率≥90%、IP 添加 100%、状态刷新≤30s、协议推荐准确率 100%、RDP/VNC 首帧成功率≥90%、键鼠映射≥99%、剪贴板≥95%、合规声明确认 100%、无明文 100%）。整体：端到端 100% 走通、P0 缺陷=0。
负向清单：不做公网中转/打洞、不自研被控端、不做移动/鸿蒙/iOS 主控、不做文件传输/账号云同步/会话录像、不用 Rust 工具链。

## 三、页面清单（7 页，四态齐全）
P-01 设备列表主窗口、P-02 添加设备弹窗、P-03 连接配置弹窗、P-04 远程会话窗口、P-05 设置页、P-06 连接历史页、P-07 合规声明页。

## 四、多平台差异
Windows→RDP 3389→系统远程桌面/TightVNC；macOS→VNC 5900→屏幕共享；Linux→VNC 5900+→x11vnc/TigerVNC；飞牛OS→VNC 5900→内置 VNC；可选 RustDesk（官方客户端，P2）。平台差异靠"协议自动推荐+部署文档"抹平。

## 五、版本路线图
V1.0 MVP（1~8 周）：F-01/02/03/04/06/07/12/15 全 P0 + F-05/09/16 + 部署文档。
V1.1（上线后 2~6 周）：F-10 历史、F-13 剪贴板、F-14 画质。
V1.2+（Q+1）：F-08 RustDesk、F-11 置顶。范围不重叠 ✓。

## 六、网络与安全需求
仅局域网；端口 3389/5900+/5353/UDP 自定义需防火墙放行；ARP 需管理员权限给降级；首次合规声明、凭据 DPAPI 加密、VNC 明文风险提示、遥测默认关、不存储被控画面。

## 七、验收指标汇总
闭环成功率≥90%、发现命中率≥90%、平台识别≥95%、连接时延 P95≤8s、键鼠映射≥99%、剪贴板≥95%、P0 缺陷=0。

## 八、风险与需确认
1 RustDesk 无 Rust 环境→列 P2 调官方编译 exe（团长已确认）；2 被控端前置需预配置测试环境；3 ARP 权限已设计降级。

## 九、需求变更管理
变更登记→影响评估→版本归属→用户确认→变更通知；禁止口头变更/静默改验收；偏差>30% 重评。

## 十、配套交付物（非开发任务）
被控端部署指引：Windows/macOS/Linux/飞牛OS 开启步骤/端口/防火墙配置，随代码交付。
