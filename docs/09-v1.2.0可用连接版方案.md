## 1. 用户四问 → 根因 → 对策

| 用户问题 | 真实根因 | v1.2.0 对策 |
|---|---|---|
| ①无法达成链接 | "连接"只调起外部客户端即标记成功，本进程不建会话；无端口预检、无失败原因提示，表现为"点了没反应" | 连接前 TCP 预检 + 延迟；失败按原因分类提示 + 按协议排查指引；调起错误文案具体化 |

## 2. 发现引擎（fingerprint.ts + manager.ts）

- **三层扫描**（254 主机 / ~15 端口规模）：
  - L1 存活快扫：{22,445,3389,5900,5666}，并发 128，超时 300ms，约 3s。
  - L2 长尾补扫：仅存活 IP + ARP 种子，扫 5901-5910/5985/5986/548/8000/8001/21116，并发 64，约 2.4s。
  - L3 服务指纹：仅对开放 (ip,port) 抓 banner，并发 32，deadline 800ms，典型 <2s。
  - mDNS 与 L1 并行发起、末尾汇总；ARP 提前读取作存活种子。
- **服务指纹**（只读握手层，不碰认证）：
  - VNC/RFB：被动读 12 字节版本串；`RFB 003.889` 为 Apple 屏幕共享强信号 → macOS。
  - SSH：被动读 `SSH-2.0-...\r\n`，含 Linux 发行版字样 → Linux。
  - HTTP：主动发 `HEAD /`，读 `Server` 头含 fnOS/飞牛 → 飞牛OS；5985/5986 → WinRM。
  - SMB：发最小 Negotiate，响应 `FF 53 4D 42` 签名。RDP：发 TPKT+X.224 CR，读 0xD0 确认（另留"端口存活+无 banner"弱判定）。
  - AFP(548) 低优先级可选。
- **防泄漏**：每个 socket 绝对 setTimeout 兜底 + settled 守卫 + data 累积 + finish 里 destroy/removeAllListeners/clearTimeout。
- **边界**：只判断"是什么服务"，不进入 TLS/NLA/鉴权层，不采集版本细节/证书，无口令或破解逻辑；零新增运行时依赖。

## 3. 端口落地（Device.detectedPorts）

- `Device.detectedPorts: number[]` 记录该 IP 上发现并识别过的开放端口。
- 存储：`DeviceRow.detectedPorts` 存 JSON；`sql-store` 建表加列 + 初始化时 `ALTER TABLE devices ADD COLUMN detectedPorts TEXT NOT NULL DEFAULT '[]'`（捕获 duplicate column 忽略），老库零丢失；`json-store` 加载时为历史行补默认值。
- 聚合：多来源候选按并集合并，指纹命中端口写入 detectedPorts。
- 连接：ConnectDialog 按协议从 detectedPorts 选端口——VNC 取 5900-5910 段首个（无则 5900），RDP 含 3389 则显式指定。解决"VNC 在 5901 发现得了却连 5900"的断点。

## 4. 账密托管与免密直连（关键链路）

### 4.1 加密格式（研究实证的陷阱）
- Electron `safeStorage` 在 Windows 输出 Chromium OSCrypt v10（base64），**mstsc 不认**，只能用于本项目自身存储。
- RDP 免密要的是**裸 DPAPI blob 的小写 hex**（等价 PowerShell `ConvertFrom-SecureString`），填入 `password 51:b:`，同机同用户才有效。
- `logoncredentials:b:` 非公开字段，禁用；`prompt for credentials:i:0` 才是免密开关；CredSSP/NLA 保持默认不降级（避免中间人风险）。

### 4.2 生成链路（密码不进 argv）
- `generateRdpPasswordHex(password)`：`spawn powershell.exe -NoProfile -NonInteractive -WindowStyle Hidden -Command <固定脚本>`，脚本等价于 `ConvertTo-SecureString` + `ConvertFrom-SecureString`；明文只经 `child.stdin.end(password)` 传入，argv/脚本/磁盘/日志均无密码。
- stdout 去换行后由 `isRdpPasswordHex` 校验（前缀 `01000000d08c9ddf` + 偶数长度 hex）；8s 超时 kill + settled 守卫。

### 4.3 端到端闭环
1. 首次连接：输入账密 →（默认开启）`credentialSet(deviceId+protocol)` 以 safeStorage 密文落库 → `sessionConnect`。
2. `SessionManager.connect`：若本次未填密码，按 deviceId+protocol 查凭据，解密 password 并回填 username+password 到 resolved。
3. `RdpAdapter.connect`：拿 resolved.password → 生成 DPAPI hex → `buildRdpContent` 写 `username:s:` / `password 51:b:` / `prompt:i:0` → 临时 .rdp（0600 权限）→ 调起 mstsc → 8s 后延时删除临时文件。
4. 下次连接：输入框为空 → 步骤 2 自动回填 → 步骤 3 免密直连。
5. 快速连接用 `quick-<IP>` 作 deviceId，保存/回填 key 一致，同样免密；协议切换/输入 IP 时自动带出已存账号名（密码不入 UI）。
6. 降级：非 Windows、PowerShell 失败/超时/格式非法、未保存密码、Credential Guard 拦截 → 回落手输并明确提示，**不绕过系统安全策略**。

## 5. 失败分类与通用直连

- `session:precheck` 在端口不通时按端口给分类 message（3389→远程桌面/非专业版/防火墙，5900-5910→屏幕共享/VNC，22→SSH）。
- ConnectDialog 失败时展示 result.message 并自动展开按协议的排查指引（RDP/VNC/通用/RustDesk 各一组）。
- QuickConnect：`parseTarget` 严格校验 IPv4 与端口，端口 3389→RDP、5900-5910→VNC 提示；协议切换智能预填默认端口（手动改过则尊重用户）。
