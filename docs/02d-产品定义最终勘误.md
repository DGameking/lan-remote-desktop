## 二、托盘态异常分支修正（采纳研发边界）
原"外部客户端关闭→本产品自动回设备列表"作废。
修正：调起成功后本产品退托盘常驻 →【主路径】用户点托盘菜单"回到设备列表"唤出主控窗口并记录会话 →【辅助路径】检测到外部进程 exit 时不直接弹回，先二次确认窗口状态（防 mstsc/VNC Viewer 单实例转交导致假退出误判），确认会话确已结束才回收至设备列表+记录历史。
新增异常分支：单实例复用误判（新 spawn 进程转交旧实例后立即 exit）→ exit 仅作辅助触发，需二次确认，主路径为托盘菜单唤回。

## 三、团长裁决：两项指标口径（研发验证后正式采纳）
1. 平台识别准确率：废除"自动识别≥95%"（VNC banner 不携带 OS 字段，mac/Linux/fnOS 同开 5900 协议层不可区分，飞牛OS 是 Linux 发行版）。新口径：Windows(3389) 高置信识别；mac/Linux/fnOS 疑似 VNC 弱提示 + 手动指定/纠正，纠正后协议推荐正确率 100%。
2. 设备发现命中率：分母=已开启 RDP/VNC 服务且网络可达的设备（端口扫描接近 100%）；未开服务的手机/IoT 不作为发现对象。
