# LanDesk 全栈系统交付全案

> 交付方：全栈智造专家团（forge-lead 整合）｜版本 v1.0.0｜日期 2026-11-18
> 需求：Windows 端局域网跨平台远程桌面主控软件，可连接 macOS / Windows / Linux / 飞牛OS(fnOS) 桌面，参照开源项目，交付上线并推送 GitHub。

---

## 一、执行摘要

LanDesk 是一款**纯局域网、零云端、零服务端**的 Windows 桌面主控程序。它把家中/办公室里的异构设备（Windows/macOS/Linux/飞牛OS）汇聚到一张设备列表，用各平台成熟的远程桌面协议直连桌面——**不自研协议栈、不捆绑第三方二进制、不需要公网中转**。

**核心路线（用户拍板 + 全团一致）**：多协议聚合。Windows 主控端自研 GUI（Electron + Vue 3 + TypeScript），集成设备发现（端口扫描为主力 + mDNS + 只读 ARP + SSDP 可选 + 手动加 IP 兜底）与协议调起（RDP→mstsc.exe、VNC→外部 Viewer、RustDesk→可选外部调起）；被控端用各平台现成开源服务/客户端。

**知识产权策略**：自研代码 MIT 许可；AGPL(GPL) 组件（RustDesk/TigerVNC）仅进程调起、不复制不捆绑，规避许可证传染。

## 三、团长裁决汇总（关键决策与理由）

| # | 决策点 | 裁决 | 理由 |
|---|---|---|---|
| 1 | 技术路线 | 多协议聚合、外部调起 | 用户拍板；无 Rust 工具链；AGPL/GPL 合规边界清晰 |
| 2 | 存储 | SQLite(sql.js WASM) 而非 JSON Store / better-sqlite3 | 兼顾关系型实体模型与零 native 编译、CI ABI 稳定 |
| 3 | 发现主路径 | 端口扫描为主力，mDNS+只读 ARP 补充，SSDP 可选，手动加 IP 兜底 | 只读 ARP 只能发现已通信设备；端口扫描最可靠 |
| 4 | 平台识别指标 | 废除"自动识别≥95%"，改 Windows 高置信 + 其余弱提示 + 手动纠正（纠正后推荐 100%） | VNC banner 不携带 OS 字段，协议层不可区分 |
| 5 | 键鼠/画面 | 归外部 mstsc/VNC Viewer，本产品不渲染不录流、不设映射率门禁 | 与外部调起模型自洽 |
| 6 | 凭据安全 | DPAPI 加密落盘；密码绝不进 argv；临时文件 try/finally 删除 | Windows 进程命令行对其他进程可见 |
| 7 | 遥测 | **首版锁定零遥测** | 虚假隐私声明是合规硬伤；已源码实证无上报模块 |
| 8 | 崩溃率指标 | 目标值≤0.1%，V2 可度量，非首版放行门禁 | 首版无数据源，设门禁会导致永远无法放行 |
| 9 | CI 卡点 | typecheck + typecheck:vue + test:unit + dist 四项硬卡点，lint 豁免 | 质量铁律不破；MVP 阶段 lint 性价比低 |
| 10 | P0 编号 | 权威 REQ-001~012，手动加 IP 由 P1 提升 P0 | 统一口径，避免代码/文档错配 |

## 五、合规与安全声明

1. **用途红线**：仅连接用户拥有或明确授权的设备；无打洞、无弱口令爆破、无绕过目标认证。
2. **许可证**：自研 MIT；RustDesk(AGPL-3.0)/TigerVNC(GPL) 仅外部调起不捆绑；noVNC(MPL-2.0) 未内嵌；FreeRDP 未使用。
3. **隐私**：v1.0.0 不采集、不上传任何诊断/遥测数据；本地日志脱敏后留存 30 天，不上报。
4. **SmartScreen**：未签名 exe 会触发 Windows 告警，README 提供"更多信息→仍要运行"引导与 SHA256 校验值；代码签名为演进项。

## 六、已知限制与演进（V2）

- 平台自动识别协议层受限（5900 无法区分 mac/Linux/fnOS），靠手动纠正兜底
- RustDesk 为可选外部调起，非深度集成
- 飞牛OS 无统一管理 API，以端口探测结果为准
- 遥测/崩溃上报、FreeRDP/noVNC 内嵌、文件传输、WoL、多显示器/音频均为 V2
- 未签名（代码签名证书为演进项）
