## 2. 功能测试用例集（按权威 REQ-001~012）

编号规则：`TC-<模块>-N##` 正常流 / `-E##` 异常流（分开编号）。每条含模板五要素（编号/模块/标题/优先级/前置/步骤/预期），下列为可执行简写。

### 2.1 REQ-001 设备自动发现（主力=端口扫描）
- `TC-DISC-N01` P0 **端口扫描主路径**（主次已对调）：前置=同 /24 网段有在线设备、当前用户无管理员权限。步骤=启动→自动扫描→等待。预期=**端口扫描(3389/5900/21116) 为主力默认启用**，5s 内返回结果（单探测超时 400ms、并发上限 50）；列出在线设备；发现命中率按分母口径统计（见 §4，交叉验证为可选人工复核、非门禁）。
- `TC-DISC-N02` P0 **ARP/mDNS 补充**：预期=mDNS 补充设备名线索、只读 ARP 表补充近期通信设备（无需管理员、不做主动 ARP 扫描、不引入 Npcap/dgram 之外的 native 依赖）；补充项去重、来源标注正确。
- `TC-DISC-E01` P0 扫描 0 台→展示 3 步排查清单（同网段？被控端远控已开？防火墙放行 3389/5900？）+ 一键重扫 + 手动添加 IP 入口；不白屏不转圈。
- `TC-DISC-E02` P1 权限/防火墙受限→不崩溃、部分结果保留、失败项标"探测受限"、日志可查。
- `TC-DISC-E03` P1 多网卡/虚拟网卡→仅本地网段，不误扫公网。

### 2.2 REQ-002 设备列表与状态
- `TC-LIST-N01` P0 每台展示 平台/IP/主机名/在线态 4 字段，平台来源标注（推断/手动），排序稳定。
- `TC-LIST-N02` P1 在线态刷新≤30s；目标关机→刷新→切离线无残留假象。
- `TC-LIST-E01` P1 列表为空→空态 + 排查清单入口。

### 2.3 REQ-003 Windows RDP 连接
- `TC-RDP-N01` P0 点击→注入凭据→调起 `mstsc.exe`。预期=**进程成功拉起且参数含目标 IP:端口即判成功（非画面首帧）**；点击→拉起 P95≤3s；调起成功率纳入≥99% 统计。
- `TC-RDP-N02` P0 二次连接凭据自动填充率 100%，不落明文。
- `TC-RDP-E01` P0 认证失败→**清除缓存凭据重新调起**→回凭据步骤；不回显密码、可重试。
- `TC-RDP-E02` P0 未装/被策略拦截/3389 关闭→提示"启用系统远程桌面或改用 VNC"，合理超时无假死。

### 2.4 REQ-004/005/006 被控端 VNC（按平台分列）

## 6. 质量门禁量化标准 + 准入/准出

### 6.1 上线门禁（任一不满足不得放行）
1. **P0 bug = 0**（存在即禁止上线）。

4. 全量用例执行率 100%，通过率 ≥95%。
5. 专项基线（按裁决口径）：发现命中率≥90%（分母=已开服务且可达设备）；调起成功率≥99%；调起时延 P95≤3s（端到端 8s 为运营观测非放行）；一键重连≥95%；自检准确率≥90%；纠正后协议推荐正确率100%；/24 端口扫描≤5s；UI P95≤200ms。
6. 兼容矩阵执行完成，无阻塞级适配问题（TB-02 替代验证 + 报告标注局限后放行）。
7. 安全测试通过，无高危漏洞（明文/注入/越权/分发违规/首版外发）。
8. 合规验证通过（首启授权声明、AGPL/GPL 说明、仅连授权设备）。
9. **首版稳定性放行依据（三要素齐备）**：① 定性 P0（启动崩溃/数据丢失）= 0；② GitHub Issues 1h≥3 例绝对数未触发；③ 用户自愿提供的脱敏日志无异常崩溃证据。三项同时满足方可放行。
   > 注：崩溃率 ≤0.1% 标注"质量目标值 / V2 可度量"，首版零遥测无法计算实际值，**不作为首版放行门禁**；`<0.5%` 运营看板告警线不出现在本方案任何门禁或告警基线；opt-in 同意率≥25% 删除（首版无遥测）；"键鼠映射≥99%""首帧≥90%"已废除，不设门禁。
